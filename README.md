# Resenha pro Windows

Aqui ficam só os instaladores do app da Resenha pro Windows. O código fica em
outro lugar.

**[Baixar o instalador](https://github.com/buza10/resenha-app/releases/latest/download/Resenha-instalador.exe)**

Para entrar, você precisa da senha do grupo. Peça para quem te passou o link.

Na primeira vez, o Windows pode mostrar "O Windows protegeu o computador".
Clique em **Mais informações** e depois em **Executar assim mesmo**. Depois de
instalado, o app se atualiza sozinho.
